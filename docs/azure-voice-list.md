# Azure voices: the English list

Every English voice Azure offered in the northcentralus region on October 24, 2026: 136 voices. Written by `tools/list_azure_voices.py`; run it again to refresh. The app's own voice picker (Settings > Azure voices) always shows the current list for your region, with a sample of each.

How to read it:

- **Name** is what to pick in the app; the code next to it is the voice's full name, which the tools and the settings file use.
- **Multilingual** voices also speak other languages, and are among Azure's newest and most natural.
- **HD** voices are Azure's highest-quality ones. They worked on the free tier when this was written.
- **Styles** are speaking styles a voice offers (for example whispering). The app does not use them yet.

Setting up and choosing a voice: [Azure voices](azure-voices.md).
